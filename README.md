## 1. 서비스 소개

JASO AI 링크
https://cody-a1-3-9jkg.vercel.app/#

```
서비스명: JASO AI

한 줄 소개:
이 서비스는 자기소개서를 작성하는 대학생과 취업 준비생을 위해 AI가 자기소개서의 문장, 구조, 구체성, 직무 적합성 등을 분석하고 개선 방향을 제안해주는 서비스입니다.

서비스 목적:
자기소개서를 작성할 때 자신의 글에서 어떤 부분이 부족한지 객관적으로 파악하기 어렵다는 문제를 해결하기 위해 제작했습니다.

사용자가 지원 직무와 자기소개서 문항 및 내용을 입력하면 AI가 채용 담당자의 관점에서 자기소개서를 분석하고, 종합 점수와 항목별 평가, 잘된 점, 개선할 점, 추천 키워드 등의 결과를 제공합니다.

이를 통해 사용자가 자신의 자기소개서를 객관적으로 확인하고 부족한 부분을 수정하여 보다 설득력 있는 자기소개서를 작성할 수 있도록 돕는 것을 목표로 합니다.

타겟 사용자:
- 자기소개서를 처음 작성하는 대학생
- 취업을 준비하고 있는 대학생 및 취업 준비생
- 자기소개서의 부족한 부분을 객관적으로 확인하고 싶은 사용자
- 지원 직무에 맞게 자기소개서를 개선하고 싶은 사용자
```

## 2. 주요 기능

```
페이지 / 섹션 구성

1. 홈

JASO AI의 서비스 목적과 주요 기능을 소개합니다.

사용자가 서비스의 기능을 확인한 후 자기소개서 분석 페이지로 이동할 수 있도록 구성했습니다.

2. 자기소개서 분석

사용자가 다음 정보를 입력하고 AI 분석을 요청할 수 있습니다.

- 지원 직무
- 자기소개서 문항
- 자기소개서 내용

입력된 데이터는 /api/analyze API를 통해 Python 백엔드로 전달되며, Gemini AI가 자기소개서를 분석합니다

3. 분석 결과

AI가 분석한 자기소개서의 종합 점수와 세부 평가 결과를 제공합니다.

다음과 같은 정보를 확인할 수 있습니다.

- 종합 점수
- 문장 표현 점수
- 구조 점수
- 구체성 점수
- 직무 적합성 점수
- 설득력 점수
- 잘된 점
- 개선할 점
- 문장별 피드백
- 수정 예시
- AI 추천 키워드
- 채용 담당자 관점의 한줄 평가

4. 작성 가이드

자기소개서를 작성할 때 활용할 수 있는 기본적인 작성 방법을 안내합니다.

- 지원동기 작성 방법
- 경험 구체화 방법
- STAR 구조 활용 방법
- 추상적인 표현 줄이기
- 직무와 경험 연결하기
- AI 핵심 기능

기능명: AI 자기소개서 분석

입력
- 지원 직무
- 자기소개서 문항
- 자기소개서 내용
- 출력

AI가 입력된 자기소개서를 분석하여 다음과 같은 결과를 제공합니다.

- 종합 점수
- 문장 표현 점수
- 구조 점수
- 구체성 점수
- 직무 적합성 점수
- 설득력 점수
- 잘된 점
- 개선할 점
- 문장별 피드백
- 수정 예시
- AI 추천 키워드
- 채용 담당자 관점의 한줄 평가
- 실패 처리

필수 입력이 없는 경우 사용자에게 입력을 요청하는 안내 메시지를 표시합니다.

예:
> 지원 직무를 입력해주세요.
또는
> 자기소개서 문항을 입력해주세요.
또는
> 자기소개서를 입력해주세요.

AI 오류 처리
AI API 요청 중 서버 오류 또는 API 오류가 발생하면 사용자에게 오류 메시지를 전달하도록 구성했습니다.

예:
>AI 분석 중 문제가 발생했습니다.

또한 AI가 예상한 JSON 형식으로 결과를 반환하지 않는 경우 JSON 결과를 찾지 못했다는 오류를 발생시켜 잘못된 결과가 화면에 표시되는 것을 방지합니다.

분석 중 상태
AI 분석 요청 중에는 분석 버튼을 비활성화하고 분석 중... 상태로 변경하여 중복 요청을 방지합니다.

```

## 4. 프로젝트 구조

```
jasoai/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
├── api/
│   └── index.py
├── images/
├── requirements.txt
├── .gitignore
└── README.md
```

### 주요 파일 설명

| 파일 / 폴더 | 설명 |
| --- | --- |
| `index.html` | 웹 서비스의 기본 HTML 구조 |
| `css/style.css` | 웹 페이지의 디자인 및 스타일 |
| `js/app.js` | 사용자 입력, 페이지 이동 및 API 요청 등 동적인 기능 |
| `api/index.py` | AI API 요청을 처리하는 Python Serverless Function |
| `images/` | 서비스에서 사용하는 이미지 파일 |
| `requirements.txt` | Python 실행에 필요한 패키지 목록 |
| `.gitignore` | API 키 및 불필요한 파일의 GitHub 업로드 방지 |
| `README.md` | 프로젝트 소개 및 실행/배포 방법 문서 |

### **API 구조**

#### **`GET /api`**

백엔드 서버가 정상적으로 실행되고 있는지 확인하기 위한 Health Check API입니다.

응답 예시:

```json
{
  "status": "ok",
  "message": "JASO AI API is running."
}
```

#### **`POST /api/analyze`**

자기소개서 분석을 요청하는 API입니다.

요청 데이터:

```json
{
  "job": "마케팅",
  "question": "지원 동기를 작성해주세요.",
  "essay": "자기소개서 내용"
}
```

Gemini API를 통해 분석한 후 JSON 형식으로 결과를 반환합니다.

## 6. 로컬 실행 방법

```
① 저장소 클론

git clone https://github.com/mmm293847/A1-3.git

cd A1-3

② 의존성 설치

pip install -r requirements.txt

③ 환경 변수 설정

프로젝트 루트에 .env 파일을 생성하고
AI API 키를 환경 변수로 설정합니다.

예:
GEMINI_API_KEY=여기에_본인의_API_키_입력

실제 API 키는 GitHub에 업로드하지 않습니다.

④ Flask 서버 실행
python -m flask --app api.index run

정상적으로 실행되면 다음과 같은 주소에서 로컬 서비스를 확인할 수 있습니다.

http://127.0.0.1:5000

⑤ API 테스트
Health Check:

http://127.0.0.1:5000/api

자기소개서 분석 API는 POST /api/analyze를 통해 요청할 수 있습니다.
```

## 7. 환경 변수 설정 방법

```
필요한 환경 변수 목록:

변수명: GEMINI_API_KEY
값: 본인의 GEMINI API 키

※ 실제 API 키는 README, 소스 코드, GitHub, 스크린샷 등에 작성하지 않습니다.

로컬 설정 방법:

프로젝트 루트에 .env 파일을 생성하고 다음과 같이 작성합니다.

GEMINI_API_KEY=여기에_본인의_API_키_입력

.env 파일은 .gitignore에 추가하여 GitHub 저장소에 업로드되지 않도록 합니다.

Vercel 환경
Vercel 프로젝트의 다음 메뉴에서 환경 변수를 설정합니다.

Settings
→ Environment Variables

변수명:

GEMINI_API_KEY

값:

본인의 Gemini API 키

환경 변수를 저장한 후 프로젝트를 다시 배포하면 배포 환경에서도 Gemini API를 사용할 수 있습니다.

⚠️ 키 유출 시 대처 방법:

API 키 보안
API 키는 소스 코드에 직접 작성하지 않고 환경 변수로 관리합니다.

실제 API 키를 다음 장소에 작성하지 않습니다.

GitHub
README.md
소스 코드
스크린샷
공개 문서
API 키가 외부에 노출되었다고 판단되는 경우 기존 키를 즉시 폐기하고 새로운 키를 발급합니다.
```

## 8. 배포 방법 (Vercel)

```
① GitHub 저장소와 Vercel 연동
Vercel에 로그인한 후 New Project를 선택합니다.

GitHub 저장소에서 JASO AI 프로젝트를 선택하고 Import합니다.

② 프로젝트 설정
프로젝트의 Root Directory와 빌드 설정을 확인합니다.

현재 프로젝트는 다음과 같은 구조를 사용합니다.

index.html
api/index.py
css/
js/

③ 환경 변수 설정
Vercel 프로젝트의

Settings
→ Environment Variables

메뉴에서 GEMINI_API_KEY를 추가합니다.

API 키는 코드에 직접 작성하지 않습니다.

④ 배포
설정을 완료한 후 Deploy를 실행합니다.

배포가 완료되면 Vercel에서 제공하는 URL로 접속하여 다음 기능을 확인합니다.

홈 화면
페이지 이동
자기소개서 입력
AI 분석 요청
분석 결과 출력
작성 가이드
⑤ 재배포
코드를 수정한 후 GitHub 저장소에 commit 및 push하면 GitHub와 Vercel이 연동된 경우 변경 사항을 기준으로 자동으로 재배포됩니다.

git add .
git commit -m "Update JASO AI"
git push

배포 후 오류가 발생하는 경우 Vercel의 Deployment Logs를 확인하여 오류 원인을 파악하고 수정합니다.

```

## 10. AI 기능 동작 예시

```
✅ 정상 입력 예시:

  - 입력:

    지원 직무:
    마케팅

    자기소개서 문항:
    우리 회사에 지원한 동기와 입사 후 이루고 싶은 목표를 작성해주세요.

    자기소개서:
    저는 사람들과 소통하는 것을 좋아하고 새로운 것을 배우는 데 관심이 많아 마케팅 직무에 지원하게 되었습니다.

    대학 생활을 하면서 다양한 팀 프로젝트와 활동을 경험했고,
    그 과정에서 협업의 중요성을 배웠습니다.

    특히 학교에서 진행한 팀 프로젝트에서 홍보를 담당한 경험이 있습니다.
    SNS를 활용하여 프로젝트를 홍보했고 많은 사람들에게 프로젝트를 알릴 수 있었습니다.

    이 경험을 통해 마케팅은 단순히 제품을 홍보하는 것이 아니라
    사람들의 관심을 끌고 원하는 정보를 전달하는 것이 중요하다는 것을 알게 되었습니다.

  - 출력:

    종합 점수와 함께 문장 표현, 구조, 구체성, 직무 적합성, 설득력에 대한 평가를 제공합니다.

    또한 잘된 점, 개선할 점, 문장별 피드백,
    수정 예시, AI 추천 키워드 및 채용 담당자 관점의 한줄 평가를 제공합니다.

⚠️ 빈 입력 예시:

  - 입력:
    자기소개서 입력란을 비워둠

  - 화면 안내 메시지:
    "자기소개서를 입력해주세요."

❌ API 오류 예시:

  - 상황:
    AI API 요청 과정에서 서버 오류 또는 API 오류가 발생함

  - 화면 안내 메시지:
    "AI 분석 중 문제가 발생했습니다. 잠시 후 다시 시도해주세요."

⏳ 응답 지연 예시:

  - 상황:
    AI 분석 결과를 기다리는 동안 응답이 지연됨

  - 화면 안내:
    "AI가 자기소개서를 분석하고 있습니다..."
    
    분석 중에는 로딩 상태를 표시하고 중복 요청을 방지합니다.
```
